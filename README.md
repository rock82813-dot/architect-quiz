# 建築師測驗

臺灣建築師考試「營建法規與實務」與「建築構造與施工」練習工具。

## 開啟

下載整份專案後，開啟 `建築師測驗/開始測驗.html`。請保留 `建築師測驗` 與 `建築師歷年考題` 兩個資料夾的相對位置。

本機 AI 功能需要 Node.js 及 Ollama，使用方式見 [使用說明](建築師測驗/使用說明.md)。GitHub 儲存庫不會自行執行本機 AI 服務。

## 功能與內容

- 民國 97–114 年，兩科共 36 份選擇題試卷、2,880 題，包含官方答案與更正答案。
- 歷屆練習、即時作答、限時模擬、提前交卷、錯題重練。
- 構造科歷屆練習、即時作答、模擬考每回 80 題；錯題重練依實際錯題數。
- AI 與離線情境題每回 80 題；依既有題型與參數組合，不代表 80 個不同考點。
- 已收錄詳解包含各選項說明及來源。**歷屆詳解尚未全部完成**，完整缺漏清單見 `建築師測驗/review-coverage.json`。
- 民國 81–96 年原始試卷另供查閱。

## 檢查

```sh
node 建築師測驗/audit-reviews.cjs
node 建築師測驗/audit-reviews.cjs --require-complete
```

第二個命令會在仍有缺漏時回傳失敗；結構檢查通過不代表法規內容已全部實質核對。

考題與官方答案來源為考選部；詳解來源附於各題。各來源內容依其原始使用條件辦理，本專案未替第三方內容另授權。
